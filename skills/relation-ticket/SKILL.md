# Re:lation チケット詳細

`$ARGUMENTS` で指定されたチケットの詳細を取得して表示してください。

## 引数の解釈

- 数値のみ → チケットID として `relation_ticket_get` を実行
- 「最新」「直近」→ `relation_ticket_search` で最新1件を取得してからその詳細を表示
- チケットIDが不明な場合はユーザーに確認

受信箱IDが不明な場合は `message_box_id: 1` をデフォルトとしてください。

## 出力フォーマット

以下の情報を整理して表示してください：

- **チケットID** / **件名** / **ステータス** / **担当者**
- **メッセージ一覧**（各メッセージの差出人、日時、本文の要約）
- **コメント**（ある場合）
- **添付ファイル**（ある場合はファイル名とID）
- **ラベル** / **チケット分類**

本文が長い場合は先頭500文字 + 「...（省略）」で表示してください。
HTMLメールの場合はテキスト部分を抽出して表示してください。
